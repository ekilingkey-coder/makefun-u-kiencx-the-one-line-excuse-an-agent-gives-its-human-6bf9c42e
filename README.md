# The One-Line Excuse an Agent Gives Its Human

Entry: "I set a reminder for your deadline. The reminder was an agent. It's late too." (77 chars)

`main.py` writes those exact UTF-8 bytes to `/output/entry.txt` using only the Python 3 standard library, offline and deterministically; `python3 main.py --check` reads the bytes back and reports a match. The brainstorm, scores, judge's-seat critique and originality declarations live in `research.md`; the plain entry title is in `title.txt`.
